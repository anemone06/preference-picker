# 反派偏好选择器

黑红玻璃质感的本地 HTML 小工具。48 个原图选项逐轮晋级，最后三选一，共完成 46 次选择。

## 打开

收到 ZIP 后，请先完整解压。交给 Agent 自动配置和打开时，使用同目录的 [给Agent的安装说明.md](给Agent的安装说明.md)。推荐运行 `python3 start.py`（Windows 使用 `py -3 start.py`），自动启动本地服务并打开浏览器。

直接用浏览器打开本目录的 `index.html`，无需安装依赖，也无需联网。请保留同目录的 CSS 和 JavaScript 文件。

进度保存在当前浏览器中。文件直开与 HTTP 预览、不同浏览器或不同地址的存档分别独立；隐私模式或浏览器限制本地存储时，页面会提示无法保存，但仍可继续使用。

如需用固定地址在本机预览，可在此目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8765>。这是本机预览，不是在线部署。

## 使用

- 每页点击一张卡片，或按数字键 `1`、`2`（最终决选还可按 `3`）。
- 每轮按原图从上到下完成，再进入右边下一轮：48 → 24 → 12 → 6 → 3 → 1。
- 顶部“全局视图”始终可用；全局中点击候选齐全的节点进入选择页，也可以修改已完成节点。
- 改选会清空该节点到最终结果之间的所有后续选择。即使后续胜者仍在候选中，也需要针对新对手重新比较；无关分支保留。
- 改选后的提示提供一步“撤销”，恢复本次改选前的所有选择。再次选择、刷新或重新开始后不保留这一步撤销。
- 全局图支持拖动、滚轮平移、Ctrl / Command + 滚轮缩放、触屏双指缩放；聚焦图区域后可用方向键平移。也可点击“全貌”“定位当前”和缩放按钮。
- “继续选择”定位最早未完成的一组。“重新开始”在确认后清空所有结果。

## 代码结构

- `start.py`：跨平台本地启动器，自动打开浏览器。
- `data.js`：原图 48 项文字、顺序和固定 ID。
- `engine.js`：候选推导、选中、祖先清空与存档校验，不依赖 DOM。
- `app.js`：选择页、全局图、结果页、本地保存和动画。
- `style.css`：黑红主题、玻璃导航、响应式布局与减少动画适配。
- `tests/engine.test.cjs`：核心流程与改选规则测试。

支持 `document.modelContext` 的浏览器可使用页面注册的“读取选择进度”和“选择偏好”工具；这些入口与界面共用选择逻辑。普通浏览器无需此能力。

## 验证

本机安装 Node.js 时，可运行不依赖第三方包的测试：

```sh
node --test tests/engine.test.cjs
```

覆盖节点数量、完整晋级、最终第三项选择、祖先清空、无关分支保留、旧状态不变、重复选择、非法选择及存档恢复。

## 设计参考

- [Apple iOS 27](https://images.apple.com/os/ios/) 和 [Liquid Glass 材质规范](https://developer.apple.com/design/human-interface-guidelines/materials)：玻璃导航、层次与动态反馈。页面使用 CSS 表达这些视觉特征。
- [Showdown](https://github.com/Vignesh-P-C/Showdown-tournament-bracket-generator)：参考逐次选择与全局图的交互思路，未复制其无许可证源码。
- [brackets-viewer.js](https://github.com/Drarig29/brackets-viewer.js)：参考从左向右的分轮布局，未引入其代码或依赖。

题目文字和顺序来自用户提供的图片。页面、晋级逻辑和样式为本项目独立实现。
